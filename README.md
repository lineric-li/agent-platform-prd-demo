# 统一 Agent 基建平台｜PRD 与交互 Demo

统一 Agent 平台产品方案及纯前端可交互演示，覆盖社区穿搭灵感、生态守护和电商售后答疑三类场景。

## 文件

- [PRD 产品方案（Word）](./PRD.doc)：包含目录、通用骨架、功能模块、MVP 边界与 Demo 界面说明。
- [交互 Demo（HTML）](./index.html)：脚本、样式与插画均内嵌，可下载后用浏览器打开。

## 体验方式

打开 `index.html` 文件页，点击 GitHub 的 Download raw file 下载文件，随后双击打开。仓库文件页展示的是代码；交互演示需要在浏览器打开 HTML，或另行部署静态页面。

## 核心流程

- 社区穿搭灵感：配置与体验 → 验证 → 审批 → 灰度试用 → 新旧版本对比 → 异常回退。
- 生态守护：社区审核与商业广告审核分域，沿用审核规范，验证不达标时阻止发布。
- 电商售后答疑：多轮补充信息 → 匹配适用条款 → 客服采纳或改写 → 知识更新与回归验证。

演示中的业务数据、审核结论、评测与流量指标均为模拟数据，不连接真实模型、内容审核或订单系统。状态保存在当前浏览器中，可使用界面上的“重置演示”恢复初始状态。
